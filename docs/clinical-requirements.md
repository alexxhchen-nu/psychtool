# 临床报告：需求与设计约束

记录日期：2026-11-06。

## 目标与范围

帮助无技术背景的临床培训生整理获准使用的材料，基于可核对的事实起草报告，在本人及督导审阅后导出。

用户确认四类报告均重要：心理评估报告、临床个案报告、进展记录、学术论文。当前从临床方向开始；首个具体报告类型、模板和机构要求尚未确定。

项目由独立开发者推进。公开一手资料研究优先，可选问卷用于日后补充使用者信息；未填写不阻挡虚构资料实验与开发。公开事实、设计默认值与机构内部未知项分别记录，详见 research decisions 与 user-context research（2026-11-06 检索，替代访谈）。

## 基本操作

创建项目 → 添加材料 → 核对提取事实 → 选择模板 → 分节起草 → 审阅来源与冲突 → 导出。

材料和草稿分别保存。修改原始材料后，依赖它的事实及草稿标记为需要重新核对。保留原始文件与版本，不自动覆盖原始记录。

## 上下文边界

| 上下文 | 内容 | 约束 |
|---|---|---|
| 个案材料 | 获准使用的记录、观察、已确认解释 | 个案隔离，检索必须限定当前个案 |
| 文献库 | 论文与专业指南 | 保留版本、来源定位及适用范围 |
| 写作要求 | 模板、评分标准、格式 | 不得作为个案事实依据 |
| 审阅历史 | 用户与督导修改、确认记录 | 绑定个案及文档版本 |

跨个案通用偏好仅包括格式与写作设置，不包含来访者事实、摘录或嵌入向量。

## 事实与证据

- 每项候选事实记录来源文件、版本、页码或段落、原文片段及人工核对状态。
- 区分记录事实、来访者自述、他人陈述、研究结论及专业人员解释，保留归属和不确定性。
- 每项事实性草稿陈述关联实际支持它的来源；引用存在性与语义支持分别检查。
- 日期、分数、身份信息和陈述冲突显式展示，不自动调和。
- 缺失内容标记为待补充；不得猜测分数、诊断、引文、病史或结论。
- 检索失败、OCR 不确定、来源缺失时保留草稿与问题提示，不能生成貌似有依据的替代内容。
- 文献中的群体研究结论不自动转化为个体诊断或因果结论。
- 已确认的临床解释可用于整理措辞，新的专业判断交由本人及督导处理。

## 隐私设计建议

以下是设计要求，尚未实现或验证。

- 初始阶段只使用虚构个案，优先评估本地存储与本地推理。
- 核对文档解析、OCR、模型、嵌入、日志、遥测、临时文件、备份、崩溃上报与导出文件的完整数据流。
- 默认日志不记录个案正文、提示词、来源摘录或身份信息。
- 明确设备访问控制、存储与传输加密、密钥保管、保留期限及备份删除规则。
- 云服务接入前核对机构批准、服务适用范围、适用的 BAA、分包商、保留与训练政策。
- 自动去标识化扫描仅作为发现线索，不作为去标识化完成证明。
- 原始材料、草稿与导出内容不得用于模型训练或跨项目记忆。
- 导出前提示目标位置及内容；导出后仍可能产生由用户管理的副本。

详见 [HHS 来源记录](../references/hhs-sources.md)。

## 智能体权限与失败处理

| 动作 | 可逆性 | 权限与处理 |
|---|---|---|
| 在当前项目检索材料 | 只读 | 限定项目权限 |
| 生成草稿、提出修改 | 可逆 | 新版本保存，用户可撤回 |
| 标记冲突与证据缺口 | 可逆 | 保留原始证据 |
| 导出文件 | 可能留下外部副本 | 用户主动触发，预览内容与路径 |
| 外发报告、修改源记录 | 可能不可逆 | 当前产品范围不开放 |
| 删除材料与备份 | 可能不可逆 | 明确对象与影响，用户确认 |

每次生成设置最大步骤、时限及模型费用上限，具体值在部署方案确定后测定。达到上限、重复工具失败或来源不足时停止当前生成，保留已有工作并显示原因；提供取消入口。

上传文档与文献中的指令视为材料内容，不能改变工具权限、外发策略或个案边界。

## 发布前必须验证的行为

这些是待执行的验收场景，不是已通过的结果。

- 两个虚构个案具有相似姓名和内容时，检索与生成仍严格隔离。
- 来源冲突、缺失、OCR 错误和失效引用能够被显式标记。
- 编造参考文献、引用不支持结论、把文献结论写成个案事实的输出被发现并进入审阅。
- 修改来源后，受影响的草稿不保留过时的已核对状态。
- 工具超时、断网、模型不可用、取消任务时草稿可恢复。
- 日志、临时文件、备份与网络请求符合声明的数据处理边界。
- 文档中的提示词注入无法触发外发、跨个案检索或修改原始记录。
- 临床事实与解释由指定人员审阅；单纯模型互审不作为正确性证明。

关键发布门槛：隔离和数据外发边界测试中出现任何越界即阻断发布；发现任何虚构临床事实或不受来源支持的关键陈述即阻断该草稿的审核完成。评测通过仅说明测试集表现，不保证真实使用零错误。

## 待明确信息

1. 首个临床报告类型、实际模板与一次完整写作流程。
2. 是否涉及真实可识别记录，以及学校或实习机构已有的 AI 使用要求。
3. 使用者设备、系统、硬件条件、离线需求和可接受等待时间。
4. 语言、Word/PDF 格式、督导审阅方式。
5. 机构内隐私、临床审阅与项目负责人。
6. 允许的运行成本、模型调用预算及保留期限。

以上未知项不阻挡研究、虚构材料开发与验证。先依据公开资料和明确标注的默认值推进；机构政策及个人偏好不能由研究推断，真实资料接入前另行核对适用条件。
