# ADR 0005：工作区为目录，实体为带版本的 JSON 文件，不引入数据库

日期：2026-11-06。状态：已确认（用户 2026-11-06 答复 Q5）；应用存储部分已被 ADR 0010 取代（2026-11-24）。

## 决策

每个个案工作区是一个目录；材料、事实清单、草稿、审阅记录分别是带稳定 ID 与版本字段的 JSON 文件。不引入 SQLite 或其他数据库。

## 理由

- 规模极小（单工作区几十条候选陈述），查询优势用不上。
- JSON 可直接打开检查、git diff 可见、损坏可手动修复；对无技术背景的最终用户，可解释性本身是资产。
- 与 fixtures 的 JSON 格式同源，评测与运行共用一套解析。

## 后果

- 每个实体文件含 `id`、`version`、`case_id`、来源定位与状态字段；版本不可变，修改写新文件。
- 若未来规模或并发增长超出纯文件能力，再评估迁移；届时 JSON 导出格式即迁移输入。
