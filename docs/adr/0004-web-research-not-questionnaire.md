# ADR 0004：使用者信息以公开网络调研替代问卷

日期：2026-11-06。状态：已确认（用户 2026-11-06 答复 Q4：无法直接访谈，改为全网检索）。

## 决策

规格中 6 项待明确信息（报告类型、数据类型、设备、语言/格式、机构负责人、预算）无法通过访谈获得，改为**公开来源网络调研**：项目官网、课程大纲、机构公开政策、专业协会公开资料。查不到的项目继续标注为未知，不用推测填补。

## 理由

- 无法联系到目标使用者本人；问卷通道不可用。
- 公开资料能覆盖课程侧重、常见报告结构、机构 AI 政策趋势等背景；个人偏好类问题注定保持未知。

## 后果

- 调研结果写入 `references/`，每条结论附来源与检索日期；区分「公开事实」与「机构内部未知」。
- 涉及具体机构政策的结论，在产品交付前仍需使用者本人确认；调研只收窄默认值的猜测范围。
