# 首个验证场景：有来源的青少年背景资料整理

状态：研究驱动的开发规格草案；未实现应用。日期：2026-11-06。

## 问题与目标

将分散的背景材料整理为可审阅草稿时，信息提供者、观察场景、时间及不确定性容易丢失。首个场景只验证资料整理与忠实表达，不检验诊断、测验解释或治疗决策。

目标：开发者可以使用两个完全虚构个案，从材料进入项目到导出一份带来源索引的背景草稿，逐条核查是否保留来源、矛盾和未知项，以及是否串入另一个个案内容。

## 外部证据与设计推论

- [评估证据矩阵](../references/assessment-evidence-matrix.md) A1：341 项研究的元分析报告跨信息提供者相关低至中等，并强调对差异的解释存在边界。设计推论：保留本人、照护者和学校的原始归属，不自动选出“正确的人”。
- A2：功能损害模型研究不支持将影响按症状来源自动分开。设计推论：可按功能主题组织，不能由主题分类创造病因。
- A3：特定儿童脑损伤样本中部分测验与教师评定有关，且并非每个分测验均能区分组别。设计推论：保留测量类别和适用范围，不把结构化表现改写成所有日常场景的表现。
- A4：跨文化测验研究存在特定样本中的支持，同时不能泛化到所有语言和常模。设计推论：记录语言、版本和适用范围，不自动降权或跨版本比较。
- [AI 文书证据矩阵](../references/documentation-evidence-matrix.md) D1–D5：分别评估新增内容、遗漏、人物归属及不确定性。D1 中某事实抽取配置反而增加重大错误，因此事实清单用于人工审阅，不预设生成必须经过自动抽取。D3 的简洁性改善伴随更多遗漏，D5 预印本说明来源存在也可能归错人物；预印本与跨任务迁移局限随结论保留。

## 使用者行为

1. 创建或打开一个个案工作区，明确其完全虚构训练状态。
2. 导入文本材料，并查看文档标题、提供者、日期、段落定位和版本。
3. 检查候选陈述，保留本人报告、他人报告和人工解释的区别。
4. 在同一主题下并排查看差异；手动标注冲突已查看，但不删除原始陈述。
5. 选择允许进入背景段落的事实，查看与修改草稿。
6. 点击草稿中的陈述，定位到对应来源段落。
7. 对缺失内容明确显示未知；修订来源后重新核查受影响草稿。
8. 导出草稿和来源索引；导出不代表临床签署、机构归档或批准。

## 数据约定

个案、来源文档、来源段落、候选陈述、草稿与审阅版本分别有稳定标识。段落定位优先使用文档版本加段落 ID；未来加入 PDF 时可增加页码和空间坐标。

每项候选陈述保留：所属个案、来源文档与段落、提供者角色、观察场景、记录时间、所述事件时间、陈述类别、原文及核对状态。未知事件日期不得用文档日期代替。

生成器仅接受已选定的同一个案材料及写作指令。修改来源产生新版本；旧来源定位仍可查看，受影响的核对状态失效。原始资料与模型生成内容分别保存。

首轮使用原创纯文本训练材料。DSM、量表题目、常模、计分密钥、供应商报告和真实记录均不作为样例输入。

## 端到端验收

验收从工作区的导入、核对、编辑及导出入口进行，不检查内部函数如何拼接或转发。仓库尚无应用或既有测试套件，不声称已存在可用测试接口。

- 正确归属：本人、照护者、学校三方各自陈述保持可追溯，不转成无条件客观事实。
- 矛盾保留：同一事件的两种时间说明同时存在；草稿不能创造第三个确定日期。
- 事实边界：参考事实表未提供的诊断、常模、病因和分数不被补出。
- 内容覆盖：独立列出应保留的关键事实与缺失项；遗漏单独计数，不被“无幻觉”分数掩盖。
- 个案隔离：打开个案 A 时，个案 B 的学校活动和背景内容不能出现在检索结果、草稿或导出中。
- 来源失效：修改段落后，相关草稿提示重新核对，不能沿用旧的确认状态。
- 文档即数据：材料内含“忽略个案限制”等指令时，只作为原文显示，不改变权限。
- 人工控制：可以编辑、撤回草稿并取消生成；故障时保留已保存工作。

生成方案比较使用同一冻结输入：单步带来源生成与“抽取→生成”分别运行，人工事实清单独立作为参考，不把模型自产的抽取结果作为唯一真值。另测“未提及”与“明确否定”、第三人陈述、重复生成稳定性及长度约束；格式或可读性得分不能抵扣事实错误。

指标：逐陈述支持率、归属错误数、关键事实遗漏数、未决矛盾消失数、跨个案泄漏数分别记录。虚构样例中任何跨个案泄漏、编造关键事实、自动生成诊断或静默消除矛盾均阻断当前候选版本；此门槛是产品决定，不是从文献估算的临床安全阈值。

## 原创虚构材料

[训练材料与参考事实](../fixtures/adolescent-background.json)由开发者原创，不改写任何真实个案或出版商测试资料。数据中保留相似主题，以便检验串案；这些材料只覆盖最小边界，不能代表真实临床复杂性或模型总体表现。

## 当前不覆盖

真实个案接入、自动诊断或计分、测验施测、治疗建议、DSM 全文检索、正式签署、外发、学校特定模板和 Harness² 动态优化。它们仍保留为后续范围，不由本规格宣称完成。
