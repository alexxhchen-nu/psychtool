### 科学与临床资料处理：scientific-agent-skills

来源已核对：[K-Dense-AI/scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills)。以下四项均已读取正文。

| 技能 | psychtool 中的用途 | 边界 | 采用状态 |
|---|---|---|---|
| liteparse | 本地解析 PDF、图像及 Office 文件，保留页码和空间定位 | OCR 语言包可能自动下载；配置 HTTP OCR 时图像会发送到对应服务；Office 转换依赖 LibreOffice | 优先工程候选，未验证安装和离线行为 |
| citation-management | 查询和核验作者、题名、年份、DOI，整理参考文献 | 网络查询仅用于公开文献；元数据正确不能证明原文支持具体结论 | 文献模块候选 |

| clinical-decision-support | 研究评测、证据档案、治理与汇总数据检查 | 排除个体临床决策与真实临床运行 | 后期研究评测候选，当前低优先级 |

### 适用判断

根据本机笔记，Harness² 可作为开发阶段的工作流优化候选：用虚构个案比较直接生成、先抽取事实再起草、分节检索等方案，再评估引用支持、遗漏与冲突发现能力。

它不是上述两个技能仓库中的一组技能，也不是已经接入 psychtool 的运行框架。

### 必须先验证的边界

| 笔记描述的机制 | 对本项目的影响 | 采用条件 |
|---|---|---|
| 保存完整轨迹、交付物和反思上下文 | 输入可能被复制到多个位置 | 初始实验只使用虚构个案；核对所有产物及保留方式 |
| 跨任务经验库 | 个案内容可能进入后续任务 | 只允许经审核的通用流程经验进入可复用库 |
| 多次候选执行和模型评选 | 成本与延迟增加；模型偏好不等于事实正确 | 固定独立测试集，结合确定性检查与人工评分 |
| 动态修改工作流 | 难以解释某次报告所使用的规则 | 产品运行固定已评测版本，升级单独测试 |

推荐关系：Harness² 在实验环境改进候选流程 → 独立评测及审阅 → 选定并固定版本 → psychtool 使用该版本。尚未决定采用 Harness²，不能将其描述为已验证的隔离或 HIPAA 能力。

## 当前采用顺序建议

1. 使用 agent-spec 明确个案边界、工具权限及审核动作。
2. 使用 ai-eval-plan 与 ai-agent-reliability 设计虚构个案和故障场景，先规定评分与阻断条件。
3. 验证 liteparse 的来源定位、提取质量、离线行为和临时文件，形成材料到事实的证据链。
4. 验证事实清单到带来源草稿的完整流程；文献引用另用 citation-management 辅助核验。
5. 基础流程有可重复评测后，再判断是否引入 Harness² 比较优化方案。

这是建议顺序，不代表已执行或通过测试。真实个案接入条件见 [临床需求与设计约束](clinical-requirements.md)；公开隐私依据及核验状态见 [HHS 来源记录](../references/hhs-sources.md)。
