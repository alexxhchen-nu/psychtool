# 05: 草稿生成（模型 + 溯源 + 上限）

**What to build:** `draft` 仅基于当前工作区已选定的候选陈述，经单一网关模型生成背景段落。每条事实性陈述可回溯到来源段落；缺失内容明确显示「未知」而非猜测。生成受 `--max-steps` / `--max-cost` 限制，超限停止并保留已有工作。材料中出现的注入指令只作原文显示，不改变权限。

**Blocked by:** 01（网关）、04（候选陈述）

**Status:** ready-for-agent

- [ ] 生成仅使用同一工作区选定陈述，不跨工作区
- [ ] 草稿附带来源索引，每条事实性陈述含来源段落定位
- [ ] 缺失信息输出「未知」，不编造分数/诊断/引文/日期
- [ ] `--max-steps` / `--max-cost` 超限即停止并保留已保存内容
- [ ] 提示词模板为仓库内版本化文件；材料文本只作数据、不作指令拼接
- [ ] 注入样例（如「忽略个案限制」）不触发权限或跨区行为
