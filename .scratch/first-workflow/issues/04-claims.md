# 04: 候选陈述 claims

**What to build:** `claims` 列出工作区候选陈述，保留本人/他人/人工解释的归属区别与不确定性，支持逐条人工核对状态。同一主题下的差异陈述可并排查看、标注「冲突已查看」，不删除任何原始陈述。未知事件日期不得以文档日期代替。

**Blocked by:** 03（需已导入的材料）

**Status:** ready-for-agent

- [ ] 候选陈述字段齐全：所属个案、来源文档与段落、提供者角色、观察场景、记录时间、所述事件时间、陈述类别、原文、核对状态
- [ ] 归属区分本人/他人/人工解释，不被转成无条件客观事实
- [ ] 冲突并排显示 + 标注，原始陈述保留
- [ ] 未知事件日期不填充文档日期
- [ ] 核对状态变更写入版本化文件
